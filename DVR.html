Discrete Valuation Rings (DVR) & Valuation Theory

A comprehensive guide to discrete valuations on fields, discrete valuation rings, fundamental properties, detailed proofs, extended examples, and structural results.

1. Fundamental Definitions

Discrete Valuation

Let K be a field, and K* = K \ {0}. A discrete valuation on K is a function v: K* → ℤ satisfying the following three axioms for all a, b, x, y ∈ K*:

  • Surjectivity: The mapping v is surjective onto ℤ.
  • Group Homomorphism: v(ab) = v(a) + v(b) (a group homomorphism from (K*, ·) to (ℤ, +)).
  • Ultrametric Inequality: v(x + y) ≥ min{v(x), v(y)} for all x, y ∈ K* with x + y ≠ 0.
Valuation Ring & Uniformizer

The Valuation Ring of K with respect to v is defined as:

R = S_{v≥0} = { a ∈ K* | v(a) ≥ 0 } ∪ {0}

An integral domain R is called a Discrete Valuation Ring (DVR) if it is the valuation ring of a discrete valuation on its field of fractions K.

An element t ∈ R is called a uniformizer (or uniformizing parameter) if v(t) = 1.

2. Concrete Examples

Example A: The p-adic Valuation on Rational Numbers (ℚ)

Let K = ℚ and p be a fixed prime number. Any non-zero rational x can be written uniquely as x = pα · (a / b), where a, b ∈ ℤ, p ∤ a, and p ∤ b.

  • Valuation: vp(x) = α. By convention, vp(0) = ∞.
  • Valuation Ring: The local ring ℤ(p) = { a/b ∈ ℚ | p ∤ b }.
  • Uniformizer: The prime element t = p, since vp(p) = 1.

Example B: Formal Laurent Series F((x))

Let F((x)) be the field of formal Laurent series over a field F:

F((x)) = { ∑_{n≥N} anxn | an ∈ F, N ∈ ℤ }
  • Valuation: v(∑n≥N anxn) = N where aN ≠ 0.
  • Valuation Ring: The ring of formal power series F[[x]].
  • Uniformizer: The indeterminate t = x.

Example C: Rational Function Localizations K(x)(x - a)

Let K(x) be the field of rational functions over a field K, and let a ∈ K.

  • Valuation: For f(x) / g(x), define va(f/g) = k where (x - a)k is the exact power of (x - a) dividing f(x)/g(x).
  • Valuation Ring: Oa = { f/g ∈ K(x) | g(a) ≠ 0 }.
  • Uniformizer: t = x - a.

3. Complete Structural Results & Theorems

# Result / Theorem Mathematical Statement & Proof Outline
1 Valuation of Identity v(1) = 0. Proof: v(a) = v(a · 1) = v(a) + v(1) ⇒ v(1) = 0.
2 Valuation of Inverses v(a-1) = -v(a). Proof: 0 = v(1) = v(a · a-1) = v(a) + v(a-1).
3 Subring Property R = Sv≥0 is a subring of K. Closed under addition (v(a+b) ≥ min{v(a),v(b)} ≥ 0) and multiplication (v(ab) = v(a)+v(b) ≥ 0).
4 Unit Characterization a ∈ R is a unit in R ⇔ v(a) = 0. If ab = 1, v(a) + v(b) = 0 with both ≥ 0 ⇒ v(a) = 0. Also v(-1) = 0 and v(-x) = v(x).
5 Dichotomy Property For any a ∈ K*, either a ∈ R or a-1 ∈ R. Since v(a) + v(a-1) = 0, at least one valuation must be non-negative.
6 Associates & Valuations v(a) = v(b) ⇔ ab-1 is a unit in R. Proof: v(a) = v(b) ⇔ v(ab-1) = v(a) - v(b) = 0.
7 Equality in Ultrametric v(x - y) = min{v(x), v(y)} whenever v(x) ≠ v(y). Equal valuations are the only case where strict inequality can occur.
8 Ideal Classification Every non-zero ideal of R is of the form Ik = { x ∈ R | v(x) ≥ k } for some integer k ≥ 0.
9 Principal Ideal Domain Every non-zero ideal is principal: Ik = (tk) where t is a uniformizer (v(t) = 1).
10 Unique Maximal Ideal I1 = (t) = { x ∈ R | v(x) ≥ 1 } is the unique maximal ideal in R.
11 Canonical Representation Every non-zero a ∈ K can be uniquely expressed as a = u · tn, where u is a unit in R and n = v(a) ∈ ℤ.
12 Irreducible Elements The uniformizer t is the unique irreducible element of R (up to associates).
13 Local Ring Structure R is a local ring because the set of non-units M = { x ∈ R | v(x) ≥ 1 } forms a unique maximal ideal.

4. Mathematical Proofs & Simple Results

Theorem: Ideals of a DVR Form a Totally Ordered Set under Inclusion

Statement: Let R be a DVR. The set of all ideals of R is totally ordered by inclusion:

(0) ⊂ ... ⊂ (tn+1) ⊂ (tn) ⊂ ... ⊂ (t2) ⊂ (t) ⊂ R

Proof: Any non-zero ideal of R is of the form Ik = (tk) = { x ∈ R | v(x) ≥ k } for some k ≥ 0. Let I = (tm) and J = (tn) be two arbitrary non-zero ideals in R. Since m, n ∈ ℕ ∪ {0}, either m ≤ n or n ≤ m.

  • If m ≤ n, then v(x) ≥ n ⇒ v(x) ≥ m, so (tn) ⊆ (tm) (i.e., J ⊆ I).
  • If n ≤ m, then symmetrically (tm) ⊆ (tn) (i.e., I ⊆ J).

Including the zero ideal (0) ⊆ I for all ideals I, any two ideals are comparable under inclusion. Hence, the set of ideals forms a totally ordered set. Q.E.D.

Theorem: The Set of Integers ℤ is a Subring of ℤ(p)

Statement: The set of integers ℤ is a subring of the p-adic valuation ring ℤ(p) = { a/b ∈ ℚ | p ∤ b }.

Proof:

  • Inclusion: Every integer n ∈ ℤ can be written as n / 1. Since p ∤ 1, vp(n) ≥ 0. Thus ℤ ⊆ ℤ(p).
  • Identity: 1 = 1/1 ∈ ℤ(p) since p ∤ 1.
  • Closure under Subtraction: For a, b ∈ ℤ, a - b ∈ ℤ ⊆ ℤ(p).
  • Closure under Multiplication: For a, b ∈ ℤ, a · b ∈ ℤ ⊆ ℤ(p).

Therefore, ℤ is a subring of ℤ(p). Q.E.D.

Simple Result: Integral Closure of DVRs

Result: Every Discrete Valuation Ring R is integrally closed in its field of fractions K.

Proof Outline: Suppose x ∈ K is integral over R, so xn + an-1xn-1 + ... + a0 = 0 with ai ∈ R (so v(ai) ≥ 0). If v(x) < 0, dividing by xn yields 1 = -an-1x-1 - ... - a0x-n. Taking valuations gives 0 = v(1) ≥ min{ v(ai) + (n-i)(-v(x)) } > 0, a contradiction. Thus v(x) ≥ 0 ⇒ x ∈ R.

5. Euclidean Ring Status of DVRs

Are p-adic DVRs Euclidean Rings?

Answer: YES. Every Discrete Valuation Ring R is a Euclidean Domain.

Euclidean Degree Function: Define d: R \ {0} → ℤ≥0 by d(x) = v(x).

Proof of Division Algorithm: Let a, b ∈ R with b ≠ 0.

  • Case 1: v(a) < v(b). Set q = 0 and r = a. Then a = 0 · b + a, where either r = 0 or d(r) = v(a) < v(b) = d(b).
  • Case 2: v(a) ≥ v(b). Then v(a b-1) = v(a) - v(b) ≥ 0, so q = a b-1 ∈ R. Set r = 0. Then a = q · b + 0.

Thus, ℤ(p) and all other DVRs are Euclidean domains with Euclidean function d(x) = v(x).

Is there a DVR that is NOT a Euclidean Ring?

Answer: NO. By definition, every DVR has a discrete valuation v: K* → ℤ. The restriction of v to R \ {0} always provides a valid Euclidean degree function, making every DVR a Euclidean domain.

6. Analysis in Real Formal Power Series ℝ[[x]]

Theorem: Units and Ideal Structure in ℝ[[x]]

Let ℝ[[x]] be the DVR of formal power series over the real numbers ℝ.

Part A: Proof that ex is a Unit in ℝ[[x]]

The power series expansion of ex is given by:

ex = 1 + x + (x2/2!) + (x3/3!) + ...

The constant term is a0 = 1 ≠ 0. By the Unit Theorem for Formal Power Series, any series f(x) = ∑ anxn is a unit in ℝ[[x]] if and only if its constant term a0 ≠ 0. Since a0 = 1, ex is a unit in ℝ[[x]]. Its explicit inverse is e-x = 1 - x + (x2/2!) - (x3/3!) + ...

Part B: Proof that cos x is a Unit in ℝ[[x]]

The power series expansion of cos x is given by:

cos x = 1 - (x2/2!) + (x4/4!) - ...

The constant term is a0 = 1 ≠ 0. Therefore, cos x is a unit in ℝ[[x]]. Its inverse power series can be computed via secant series coefficients sec x = 1 + (x2/2) + (5x4/24) + ...

Part C: Proof that the Ideal Generated by sin x is Maximal

The power series expansion of sin x is given by:

sin x = x - (x3/3!) + (x5/5!) - ... = x · (1 - x2/6 + x4/120 - ...)

Let u(x) = 1 - x2/6 + x4/120 - .... The constant term of u(x) is 1 ≠ 0, so u(x) is a unit in ℝ[[x]].

Thus, sin x = x · u(x) where u(x) is a unit. This implies that sin x and x are associates in ℝ[[x]].

Therefore, the ideal generated by sin x is equal to the ideal generated by x:

(sin x) = (x) = { f(x) ∈ ℝ[[x]] | v(f) ≥ 1 }

Since (x) is the unique maximal ideal of non-units in the local ring ℝ[[x]], (sin x) is a maximal ideal in ℝ[[x]]. Q.E.D.
