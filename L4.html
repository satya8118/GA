§1 Simple and non-simple extensions

Definition An extension $\mathbb{K}/\mathbb{F}$ is simple if $\mathbb{K}=\mathbb{F}(\gamma)$ for a single element $\gamma$ (a primitive element). Otherwise it is non-simple. Recall (Lecture 2): if $\gamma$ is algebraic with minimal polynomial $q$ of degree $n$ then $$\mathbb{F}(\gamma)=\mathbb{F}[\gamma]\cong\mathbb{F}[x]/\langle q\rangle,\qquad \text{basis }1,\gamma,\dots,\gamma^{n-1};$$ if $\gamma$ is transcendental, $\mathbb{F}(\gamma)\cong\mathbb{F}(x)$, the field of rational functions.
Examples of simple extensions
  1. $\mathbb{C}=\mathbb{R}(i)$, degree 2, basis $\{1,i\}$.
  2. $\mathbb{Q}(\sqrt2)=\{a+b\sqrt2\}$, minimal polynomial $x^2-2$.
  3. $\mathbb{Q}(\sqrt[3]2)=\{a+b\sqrt[3]2+c\sqrt[3]4\}$, degree 3 (Eisenstein).
  4. $\mathbb{Q}(\zeta_p)$, degree $p-1$, minimal polynomial $1+x+\dots+x^{p-1}$.
  5. $\mathbb{Q}(\pi)\cong\mathbb{Q}(x)$: a simple transcendental extension (infinite degree).
  6. $\mathbb{F}_9=\mathbb{F}_3(i)=\mathbb{F}_3[x]/\langle x^2+1\rangle$: here $1+i$ generates the cyclic group $\mathbb{F}_9^\times$ (order 8).
  7. $\mathbb{Q}(\sqrt2,\sqrt3)=\mathbb{Q}(\sqrt2+\sqrt3)$: looks like two generators, but is simple (§4).
Question 1 Show $\mathbb{F}_9^\times$ is generated by $1+i$, so $\mathbb{F}_9=\mathbb{F}_3(1+i)$.
$(1+i)^2=2i$, $(1+i)^4=(2i)^2=4i^2=-4\equiv2=-1$, so $(1+i)^8=1$ and the order is $8$ (it does not divide $4$). A group of order 8 with an element of order 8 is cyclic, generated by it.

Non-simple extensions — three flavours
  1. Infinite algebraic: $\mathbb{Q}(\sqrt2,\sqrt3,\sqrt5,\sqrt7,\dots)$ is not simple. A simple algebraic extension $\mathbb{F}(\gamma)$ has finite degree $\deg q$, whereas this one has infinite degree.
  2. Too many transcendentals: $\mathbb{Q}(x,y)/\mathbb{Q}$ is not simple: any $\mathbb{Q}(\gamma)$ has transcendence degree $\le1$.
  3. Finite but inseparable: $\mathbb{K}=\mathbb{F}_p(x,y)$ over $\mathbb{F}=\mathbb{F}_p(x^p,y^p)$ (the classical example).
Question 2 — the classical non-simple extension Let $\mathbb{F}=\mathbb{F}_p(x^p,y^p)\subset\mathbb{K}=\mathbb{F}_p(x,y)$. Show $[\mathbb{K}:\mathbb{F}]=p^2$ but every $z\in\mathbb{K}$ has $[\mathbb{F}(z):\mathbb{F}]\le p$. So $\mathbb{K}/\mathbb{F}$ is not simple.
The Frobenius map $z\mapsto z^p$ is a ring homomorphism in characteristic $p$. Where does it send $\mathbb{K}$?
Degree. $x$ is a root of $T^p-x^p\in\mathbb{F}[T]$, irreducible, so $[\mathbb{F}(x):\mathbb{F}]=p$; then $y$ is a root of $T^p-y^p$ over $\mathbb{F}(x)$, still of degree $p$. Tower Law: $p\cdot p=p^2$; basis $x^iy^j$ ($0\le i,j Every element has degree $\le p$. In characteristic $p$, $(\sum c_{ij}x^iy^j)^p=\sum c_{ij}^p x^{ip}y^{jp}\in\mathbb{F}_p(x^p,y^p)=\mathbb{F}$ and, for rational functions, the same holds (quotients). So $z^p\in\mathbb{F}$, and $z$ is a root of $T^p-z^p\in\mathbb{F}[T]$: $[\mathbb{F}(z):\mathbb{F}]\le p
A criterion (Steinitz) A finite extension $\mathbb{K}/\mathbb{F}$ is simple iff it has only finitely many intermediate fields. Example: $\mathbb{Q}(\sqrt2,\sqrt3)$ has exactly 5 (including $\mathbb{Q}$ and itself): $\mathbb{Q},\mathbb{Q}(\sqrt2),\mathbb{Q}(\sqrt3),\mathbb{Q}(\sqrt6),\mathbb{Q}(\sqrt2,\sqrt3)$. The extension above has infinitely many, consistent with it being non-simple.
Question 3 A finite simple extension $\mathbb{F}(\gamma)$: why are there only finitely many intermediate fields?
Let $q$ be the minimal polynomial of $\gamma$ over $\mathbb{F}$. For an intermediate field $\mathbb{M}$, let $r$ be the minimal polynomial of $\gamma$ over $\mathbb{M}$; then $r\mid q$ in $\mathbb{M}[x]$ and $\mathbb{M}$ is generated over $\mathbb{F}$ by the coefficients of $r$ (a field $\mathbb{M}_0$ generated by those coefficients satisfies $[\mathbb{F}(\gamma):\mathbb{M}_0]=\deg r=[\mathbb{F}(\gamma):\mathbb{M}]$, so $\mathbb{M}_0=\mathbb{M}$). Since $q$ has finitely many monic divisors in a splitting field, there are finitely many possible $r$, hence finitely many $\mathbb{M}$.

§2 Separable extensions

Definitions A non-zero $f\in\mathbb{F}[x]$ is separable if it has no repeated roots in a splitting field. An algebraic $\alpha\in\mathbb{K}$ is separable over $\mathbb{F}$ if its minimal polynomial is separable. $\mathbb{K}/\mathbb{F}$ is separable if every element of $\mathbb{K}$ is separable over $\mathbb{F}$ (otherwise inseparable).
Derivative test $f$ has a repeated root $\iff\gcd(f,f')\ne1$. Consequently an irreducible $f$ is inseparable iff $f'=0$, i.e. only in characteristic $p$ with $f(x)=g(x^p)$.
Question 4 Prove the derivative test.
If $f=(x-a)^2h$ in a splitting field, then $f'=2(x-a)h+(x-a)^2h'$ vanishes at $a$, so $(x-a)\mid\gcd(f,f')$. Conversely if $\gcd(f,f')\ne1$ over $\mathbb{F}$ (and the gcd is unchanged by field extension), it has a root $a$ in the splitting field; $f(a)=f'(a)=0$ gives $f=(x-a)h$, $f'=h+(x-a)h'$, so $h(a)=0$ and $a$ is a double root. For irreducible $f$: $\gcd(f,f')$ divides $f$, so it is $1$ or $f$ (associate); it is $f$ iff $f\mid f'$, which for $\deg f'<\deg f$ means $f'=0$. ∎
Examples
  1. Separable: $x^2-2$ over $\mathbb{Q}$: $f'=2x$ and $\gcd=1$; roots $\pm\sqrt2$. $x^n-1$ over $\mathbb{Q}$: $\gcd(x^n-1,nx^{n-1})=1$, roots $\zeta_n^k$ all distinct.
  2. Characteristic 0: every irreducible $f$ has $f'\ne0$, so every algebraic extension of a field of characteristic 0 is separable. So $\mathbb{Q}(\sqrt[3]2)$, $\mathbb{Q}(\zeta_n)$ and $\mathbb{Q}(\sqrt2,\sqrt3,\sqrt5,\dots)$ are all separable over $\mathbb{Q}$.
  3. Finite fields (and any field with $\mathbb{F}^p=\mathbb{F}$, called perfect) have only separable extensions: $x^p-a=(x-a^{1/p})^p$ is never irreducible with $\mathbb{F}$ perfect.
  4. Reducible but not separable: $x^2+1=(x+1)^2$ over $\mathbb{F}_2$; $x^p-1=(x-1)^p$ over $\mathbb{F}_p$. (Their irreducible factors $x+1$, $x-1$ are separable.)
  5. Irreducible but inseparable: $x^p-t$ over $\mathbb{F}_p(t)$ (irreducible since $t$ is not a $p$-th power; derivative $px^{p-1}=0$). Over its splitting field, $x^p-t=(x-t^{1/p})^p$.
  6. $\mathbb{F}_p(t)/\mathbb{F}_p(t^p)$ is purely inseparable of degree $p$: it is simple (generated by $t$) and inseparable.
Try it — repeated roots mod $p$ prime $p=$ coefficients (highest first):
p=3, 1,0,0,-1 is $x^3-1=(x-1)^3$: not separable. p=2, 1,1,1: $x^2+x+1$, separable. p=5, 1,0,0,0,0,-1 is $x^5-1=(x-1)^5$. p=5, 1,0,-1: $x^2-1$ separable. Over $\mathbb{Q}$ use a large prime $p$ as a heuristic.
Good behaviour of separability (1) Tower: $\mathbb{L}/\mathbb{F}$ separable $\iff$ $\mathbb{L}/\mathbb{K}$ and $\mathbb{K}/\mathbb{F}$ separable. (2) The compositum of separable extensions is separable. (3) If $\mathbb{K}=\mathbb{F}(\alpha_1,\dots,\alpha_n)$ with each $\alpha_i$ separable, then $\mathbb{K}/\mathbb{F}$ is separable. (4) Finite $+$ separable $\Rightarrow$ simple (§4).
Question 5 Is $\mathbb{F}_p(t)/\mathbb{F}_p(t^p)$ separable? Is $\mathbb{F}_p(t)/\mathbb{F}_p$ separable?
The first is not: $t$ has minimal polynomial $x^p-t^p=(x-t)^p$, a repeated root. The second is also not algebraic ($t$ is transcendental), so the question of separability does not even arise; $\mathbb{F}_p(t)/\mathbb{F}_p$ is "separably generated" in a broader sense.

§3 Splitting fields

Definition Let $f\in\mathbb{F}[x]$ of degree $n\ge1$. A splitting field of $f$ over $\mathbb{F}$ is an extension $\mathbb{K}$ such that (i) $f=c(x-\alpha_1)\cdots(x-\alpha_n)$ in $\mathbb{K}[x]$, and (ii) $\mathbb{K}=\mathbb{F}(\alpha_1,\dots,\alpha_n)$ — the smallest field where $f$ splits.
Theorem (existence, bound, uniqueness) Every $f$ has a splitting field $\mathbb{K}$ over $\mathbb{F}$ with $[\mathbb{K}:\mathbb{F}]\le n!$, and any two splitting fields of $f$ over $\mathbb{F}$ are isomorphic over $\mathbb{F}$.
Question 6 Prove existence and the bound $n!$.
Induct on $n$. Take an irreducible factor $g$ of $f$ and $\mathbb{F}_1=\mathbb{F}[x]/\langle g\rangle$ (Lecture 2); $f$ has a root $\alpha_1\in\mathbb{F}_1$, $[\mathbb{F}_1:\mathbb{F}]\le n$, and $f=(x-\alpha_1)f_1$ with $\deg f_1=n-1$. By induction $f_1$ has a splitting field $\mathbb{K}$ over $\mathbb{F}_1$ of degree $\le(n-1)!$; then $\mathbb{K}=\mathbb{F}_1(\alpha_2,\dots,\alpha_n)=\mathbb{F}(\alpha_1,\dots,\alpha_n)$ splits $f$ and $[\mathbb{K}:\mathbb{F}]\le n\cdot(n-1)!=n!$. ∎ (Uniqueness uses the extension theorem of §5.)

Question 7 — the splitting field of $x^3-2$ Show the splitting field $\mathbb{L}$ of $x^3-2$ over $\mathbb{Q}$ is $\mathbb{Q}(\sqrt[3]2,\omega)$ ($\omega=e^{2\pi i/3}$) with $[\mathbb{L}:\mathbb{Q}]=6$.
The roots are $\sqrt[3]2,\ \omega\sqrt[3]2,\ \omega^2\sqrt[3]2$. Use the Tower Law with $\mathbb{Q}\subset\mathbb{Q}(\sqrt[3]2)\subset\mathbb{L}$.
Roots: $\alpha,\omega\alpha,\omega^2\alpha$ with $\alpha=\sqrt[3]2$; so $\mathbb{L}=\mathbb{Q}(\alpha,\omega\alpha,\omega^2\alpha)=\mathbb{Q}(\alpha,\omega)$ (as $\omega=\omega\alpha/\alpha$). $[\mathbb{Q}(\alpha):\mathbb{Q}]=3$. Since $\mathbb{Q}(\alpha)\subset\mathbb{R}$ and $\omega\notin\mathbb{R}$, $\omega\notin\mathbb{Q}(\alpha)$; $\omega$ is a root of $x^2+x+1$, so $[\mathbb{L}:\mathbb{Q}(\alpha)]=2$. Tower Law: $3\cdot2=6$. ∎

Question 8 — splitting field degree can be less than $n!$ Show the splitting field of $x^3-3x+1$ over $\mathbb{Q}$ has degree $3$, not $6$.
With $y=2\cos\theta$ one has $y^3-3y=2\cos3\theta$. Show the other roots are polynomials in one root.
Let $y=2\cos\frac{2\pi}9$: $y^3-3y=2\cos\frac{2\pi}3=-1$, so $y$ is a root. The polynomial has no rational root ($\pm1$ fail), so it is irreducible of degree 3 and $[\mathbb{Q}(y):\mathbb{Q}]=3$. Also $2\cos\frac{4\pi}9=y^2-2$ and $2\cos\frac{8\pi}9=-y^2-y+2$ lie in $\mathbb{Q}(y)$ (check: the three roots sum to $0$). So $\mathbb{Q}(y)$ already contains all roots: the splitting field has degree $3$. (Its discriminant $81=9^2$ is a square, the Galois group is $A_3=\mathbb{Z}_3$.)
Question 9 — $\mathbb{Q}(\sqrt[3]2)$ is not a splitting field Why is $\mathbb{Q}(\sqrt[3]2)$ not the splitting field of any polynomial, although it contains a root of the irreducible $x^3-2$?
A splitting field containing one root of an irreducible polynomial contains all of its roots (normality). But $\mathbb{Q}(\sqrt[3]2)\subset\mathbb{R}$ misses the non-real roots $\omega\sqrt[3]2,\omega^2\sqrt[3]2$ of $x^3-2$. So $\mathbb{Q}(\sqrt[3]2)/\mathbb{Q}$ is not normal.
Question 10 Find the splitting field and degree of $x^4-2$ over $\mathbb{Q}$, and of $x^4+1$.
$x^4-2$: roots $i^k\sqrt[4]2$, so the splitting field is $\mathbb{Q}(\sqrt[4]2,i)$. $[\mathbb{Q}(\sqrt[4]2):\mathbb{Q}]=4$ (Eisenstein) and $i\notin\mathbb{R}$, so the degree is $8$ (group $D_4$). $x^4+1$: roots $\zeta_8^{1,3,5,7}$, all powers of $\zeta_8$, so the splitting field is $\mathbb{Q}(\zeta_8)$, of degree $\varphi(8)=4$.

§4 The primitive element theorem

Theorem Let $\mathbb{K}/\mathbb{F}$ be a finite separable extension. Then $\mathbb{K}=\mathbb{F}(\gamma)$ for some $\gamma\in\mathbb{K}$. In particular every finite extension of a field of characteristic $0$, and every finite extension of a finite field, is simple.
Proof idea (full proof in Lecture 3) Finite $\mathbb{F}$: $\mathbb{K}^\times$ is cyclic; a generator is primitive. Infinite $\mathbb{F}$: reduce to $\mathbb{K}=\mathbb{F}(\alpha,\beta)$. Take $\gamma=\alpha+c\beta$ where $c\in\mathbb{F}$ avoids the finitely many values with $\alpha_i+c\beta_j=\alpha+c\beta$ ($j\ne1$). Then $\gcd(f(\gamma-cx),g(x))=x-\beta$ forces $\beta\in\mathbb{F}(\gamma)$, hence $\alpha\in\mathbb{F}(\gamma)$.
Worked examples
  1. $\mathbb{Q}(\sqrt2,\sqrt3)$: $\gamma=\sqrt2+\sqrt3$, $\gamma^2=5+2\sqrt6$, $(\gamma^2-5)^2=24$, so $\gamma^4-10\gamma^2+1=0$ (degree 4). Recover $\sqrt6=(\gamma^2-5)/2$, $\sqrt2=(2+\sqrt6)/\gamma$, $\sqrt3=\gamma-\sqrt2$.
  2. $\mathbb{Q}(\sqrt2,i)$: $\gamma=\sqrt2+i$, $\gamma^2=1+2\sqrt2 i$, $(\gamma^2-1)^2=-8$, so $\gamma^4-2\gamma^2+9=0$. This is the field $\mathbb{Q}(\zeta_8)$: also $\zeta_8=\frac{\sqrt2}2(1+i)$ is a primitive element.
  3. $\mathbb{Q}(\sqrt[3]2,\omega)$: $\gamma=\sqrt[3]2+\omega$ works, degree $6$. (The bad $c$'s for $\alpha+c\beta$ are $c=0$ and non-rational values, so $c=1$ is fine.)
  4. $\mathbb{Q}(\sqrt2,\sqrt3,\sqrt5)=\mathbb{Q}(\sqrt2+\sqrt3+\sqrt5)$, degree 8, minimal polynomial of degree 8.
  5. $\mathbb{F}_{p^n}$ over $\mathbb{F}_p$: a generator $g$ of $\mathbb{F}_{p^n}^\times$; e.g. $\mathbb{F}_9=\mathbb{F}_3(1+i)$ (Question 1).
  6. $\mathbb{Q}(\sqrt[4]2,i)$ (degree 8): $\gamma=\sqrt[4]2+i$ works as well; generically $\alpha+c\beta$ with $c\in\mathbb{Q}$ almost always does.
Question 11 Find the minimal polynomial of $\gamma=\sqrt2+\sqrt3+\sqrt5$ not by expanding fully, but by finding its conjugates.
The conjugates are $\pm\sqrt2\pm\sqrt3\pm\sqrt5$ (8 numbers, all distinct), so the minimal polynomial is $\prod(x\pm\sqrt2\pm\sqrt3\pm\sqrt5)$, of degree 8 with rational coefficients: $x^8-40x^6+352x^4-960x^2+576$. (Degree 8 confirms $[\mathbb{Q}(\gamma):\mathbb{Q}]=8=[\mathbb{Q}(\sqrt2,\sqrt3,\sqrt5):\mathbb{Q}]$, so $\gamma$ is primitive.)
Question 12 — the theorem fails without separability Explain why the primitive element theorem cannot hold for $\mathbb{F}_p(x,y)/\mathbb{F}_p(x^p,y^p)$.
The extension is finite (degree $p^2$) but not separable: $x$ has minimal polynomial $T^p-x^p=(T-x)^p$. By Question 2 it is not simple. The theorem needs separability exactly to ensure that $g$ has distinct roots $\beta_j$ in the gcd argument.

§5 Automorphisms fixing the ground field; roots go to roots

Definition Let $\mathbb{K}/\mathbb{F}$ be an extension. $\mathrm{Aut}(\mathbb{K}/\mathbb{F})=\{\sigma:\mathbb{K}\to\mathbb{K}\ \text{field automorphism with}\ \sigma(a)=a\ \ \forall a\in\mathbb{F}\}$. It is a group under composition; for a Galois extension it is the Galois group.
Theorem 1 (roots go to roots) Let $\sigma\in\mathrm{Aut}(\mathbb{K}/\mathbb{F})$, $f\in\mathbb{F}[x]$ and $\alpha\in\mathbb{K}$ with $f(\alpha)=0$. Then $f(\sigma(\alpha))=0$. So $\sigma$ permutes the roots of $f$ lying in $\mathbb{K}$.
Question 13 Prove Theorem 1 and the permutation statement.
If $f=\sum c_ix^i$ with $c_i\in\mathbb{F}$ and $f(\alpha)=0$, apply $\sigma$: $0=\sigma(\sum c_i\alpha^i)=\sum\sigma(c_i)\sigma(\alpha)^i=\sum c_i\sigma(\alpha)^i=f(\sigma(\alpha))$. Hence $\sigma$ maps the finite set $R$ of roots of $f$ in $\mathbb{K}$ into itself; it is injective, so it is a bijection of $R$. ∎
Consequence: an automorphism of a simple extension $\mathbb{F}(\alpha)$ is determined by $\sigma(\alpha)$, which must be a root of the minimal polynomial: $|\mathrm{Aut}(\mathbb{F}(\alpha)/\mathbb{F})|\le[\mathbb{F}(\alpha):\mathbb{F}]$. In general $|\mathrm{Aut}(\mathbb{K}/\mathbb{F})|\le[\mathbb{K}:\mathbb{F}]$.
Theorem 2 (extension theorem) If $\alpha,\beta$ are roots of the same irreducible $p\in\mathbb{F}[x]$ (in some extensions), there is a unique isomorphism $\tau:\mathbb{F}(\alpha)\to\mathbb{F}(\beta)$ fixing $\mathbb{F}$ with $\tau(\alpha)=\beta$. Consequently, in a splitting field $\mathbb{K}$ of $f$, $\mathrm{Aut}(\mathbb{K}/\mathbb{F})$ acts transitively on the roots of each irreducible factor of $f$, and $|\mathrm{Aut}(\mathbb{K}/\mathbb{F})|=[\mathbb{K}:\mathbb{F}]$ when $f$ is separable.
Question 14 Prove the first part of Theorem 2.
$\mathbb{F}(\alpha)\cong\mathbb{F}[x]/\langle p\rangle\cong\mathbb{F}(\beta)$ (Lecture 2, minimal polynomial of both is $p$ up to scaling), via $\alpha\mapsto x+\langle p\rangle\mapsto\beta$. Uniqueness: an isomorphism fixing $\mathbb{F}$ is determined by the image of $\alpha$. ∎ Example: $\mathbb{Q}(\sqrt[3]2)\cong\mathbb{Q}(\omega\sqrt[3]2)$, two different subfields of $\mathbb{C}$ that are isomorphic but not equal.

Question 15 — roots go to roots, in action The conjugates of $\gamma=\sqrt2+\sqrt3$ are the roots of $x^4-10x^2+1$. Which automorphism sends $\gamma$ to $-\sqrt2+\sqrt3$?
The roots are $\pm\sqrt2\pm\sqrt3$. The automorphism with $\sqrt2\mapsto-\sqrt2$, $\sqrt3\mapsto\sqrt3$ gives $\gamma\mapsto-\sqrt2+\sqrt3$. Four automorphisms, four roots: since $\gamma$ is primitive, $\sigma\mapsto\sigma(\gamma)$ is a bijection from the group to the roots of the minimal polynomial.
Question 16 Show $\mathrm{Aut}(\mathbb{R}/\mathbb{Q})$ is trivial.
An automorphism preserves squares, hence positivity, hence order.
Let $\sigma\in\mathrm{Aut}(\mathbb{R})$. It fixes $\mathbb{Q}$. If $a>0$ then $a=b^2$ and $\sigma(a)=\sigma(b)^2>0$, so $\sigma$ preserves order: $ax$). So $\sigma=\mathrm{id}$. Contrast: $\mathrm{Aut}(\mathbb{C}/\mathbb{Q})$ is enormous (uncountable) though only conjugation is continuous.
Question 17 The fixed field of a subgroup $H\le\mathrm{Aut}(\mathbb{K}/\mathbb{F})$ is $\mathbb{K}^H=\{a:\sigma(a)=a\ \forall\sigma\in H\}$. Compute $\mathbb{K}^H$ for $\mathbb{K}=\mathbb{Q}(\sqrt[3]2,\omega)$ and $H=\langle\sigma\rangle$ with $\sigma(\sqrt[3]2)=\omega\sqrt[3]2$, $\sigma(\omega)=\omega$.
$\sigma$ has order 3 ($\sigma^3(\sqrt[3]2)=\omega^3\sqrt[3]2=\sqrt[3]2$), so $|H|=3$ and $[\mathbb{K}:\mathbb{K}^H]=3$ (Artin). $\sigma$ fixes $\omega$, hence $\mathbb{Q}(\omega)\subseteq\mathbb{K}^H$, and $[\mathbb{K}:\mathbb{Q}(\omega)]=3$, so $\mathbb{K}^H=\mathbb{Q}(\omega)$ — the "$\mathbb{Q}(\omega)$" box in the lattice above, fixed by $A_3$.

§7 SAQ — Short Answer Questions

Answer on paper first, then reveal.

SAQ 1Define a simple extension and a primitive element.
$\mathbb{K}/\mathbb{F}$ is simple if $\mathbb{K}=\mathbb{F}(\gamma)$; $\gamma$ is a primitive element.
SAQ 2Give an infinite algebraic non-simple extension of $\mathbb{Q}$.
$\mathbb{Q}(\sqrt2,\sqrt3,\sqrt5,\dots)$ (or $\overline{\mathbb{Q}}$).
SAQ 3State the derivative test for separability.
$f$ has a repeated root iff $\gcd(f,f')\ne1$.
SAQ 4Define a splitting field and give the bound on its degree.
The smallest extension in which $f$ factors into linear factors; $[\mathbb{K}:\mathbb{F}]\le n!$.
SAQ 5State the primitive element theorem.
A finite separable extension is simple.
SAQ 6Why must an automorphism fixing $\mathbb{F}$ map roots of $f\in\mathbb{F}[x]$ to roots?
It fixes the coefficients of $f$, so $f(\sigma\alpha)=\sigma(f(\alpha))=0$.
SAQ 7What is $\mathrm{Aut}(\mathbb{F}_{p^n}/\mathbb{F}_p)$?
Cyclic of order $n$, generated by the Frobenius $z\mapsto z^p$.
