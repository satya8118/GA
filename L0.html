Seven Lectures on Field Extensions

Lecture 0
Background You Need Before Lecture 1

Rings, ideals, $\mathbb{F}[x]$ as a PID, and maximal ideals ↔ irreducible polynomials.
Standing convention Throughout this series, ring means commutative ring with unity $1\ne0$. A field is a ring in which every non-zero element is a unit; an integral domain (ID) is a ring with no non-zero zero divisors.

§1 Elements of a ring

Definitions Let $a\in R$.
  1. Unit: $ab=1$ for some $b$. The units form an abelian group $U(R)=R^\times$.
  2. Zero divisor: $ab=0$ for some $b\ne0$ ($0$ counts when $R\ne0$). Set: $\mathcal Z(R)$.
  3. Nilpotent: $a^k=0$ for some $k\ge1$. Set: $\mathrm{Nil}(R)$.
  4. Idempotent: $a^2=a$.
  5. Irreducible: non-zero, non-unit, and $a=bc\Rightarrow b$ or $c$ is a unit.
  6. Prime: non-zero, non-unit, and $a\mid bc\Rightarrow a\mid b$ or $a\mid c$.
  7. Associates: $b=au$ for a unit $u$; this is an equivalence relation.
Question 1 Can an element be both a unit and a zero divisor?
No. If $a$ is a unit and $ab=0$, then $b=a^{-1}ab=a^{-1}\cdot0=0$, contradicting $b\ne0$. So $U(R)\cap\mathcal Z(R)=\emptyset$.
Question 2 In a finite ring, is every element a unit or a zero divisor?
Look at $f_a:R\to R$, $x\mapsto ax$. On a finite set, injective ⇔ surjective.
Yes. If $f_a$ is injective it is surjective, so $ab=1$ for some $b$: $a$ is a unit. If not injective, $ax_1=ax_2$ with $x_1\ne x_2$, so $a(x_1-x_2)=0$ with $x_1-x_2\ne0$: $a$ is a zero divisor. Hence $R=U(R)\cup\mathcal Z(R)$. (The same holds for $M_n(\mathbb{R})$ via determinants, for $\mathbb{Z}_n$, for $k[x]/\langle x^2\rangle$.)
Question 3 Is a nilpotent element always a zero divisor? Is a zero divisor always nilpotent?
Nilpotent ⇒ zero divisor: for $a\ne0$ take the least $k\ge2$ with $a^k=0$; then $a\cdot a^{k-1}=0$ and $a^{k-1}\ne0$. So $\mathrm{Nil}(R)\subseteq\mathcal Z(R)$. Converse false: in $\mathbb{Z}_6$, $\bar2\cdot\bar3=0$, but $\bar2^n\in\{\bar2,\bar4\}$ is never $0$.
Question 4 — a finite domain Show that a finite integral domain is a field.
By Question 2 every non-zero element is a unit or a zero divisor; in a domain there are no non-zero zero divisors, so every non-zero element is a unit. This is why $\mathbb{Z}_p$ ($p$ prime) is a field.

Question 5 — prime vs irreducible Show that in an integral domain every prime element is irreducible. Is the converse true?
Let $p$ be prime and $p=bc$. Then $p\mid bc$, so say $p\mid b$, $b=pd$; then $p=pdc$, so $dc=1$ (cancel in a domain) and $c$ is a unit. Hence $p$ is irreducible. Converse fails in general (e.g. $3$ in $\mathbb{Z}[\sqrt{-5}]$: $3$ is irreducible, but $3\mid(1+\sqrt{-5})(1-\sqrt{-5})=6$ without dividing either factor), but it holds in a PID — which is why in $\mathbb{F}[x]$ "irreducible" and "prime" mean the same.

§2 Ideals, quotients and maximal ideals

Definitions An ideal $I\subseteq R$ is an additive subgroup with $rI\subseteq I$. The principal ideal $\langle a\rangle=Ra$. $I$ is maximal if $I\ne R$ and no ideal lies strictly between $I$ and $R$. $\ \langle a\rangle\subseteq\langle b\rangle\iff b\mid a$; $\ \langle a\rangle=\langle b\rangle$ (in a domain) iff $a,b$ are associates; $\langle a\rangle=R$ iff $a$ is a unit.
Theorem 1 $I$ is a maximal ideal of $R$ $\iff$ $R/I$ is a field.
Question 6 Prove Theorem 1.
For ⇒ use $J=I+\langle a\rangle$ for $a\notin I$. For ⇐ use that a non-zero coset has an inverse.
(⇒) $I\ne R$, so $1+I\ne0+I$. For $a\notin I$ the ideal $J=I+\langle a\rangle\supsetneq I$, so $J=R$ and $1=i+ra$; hence $(r+I)(a+I)=1+I$, so $a+I$ is invertible.
(⇐) Let $I\subsetneq J$ and pick $x\in J\setminus I$. Then $x+I$ has an inverse $y+I$: $1-xy\in I\subseteq J$. Also $xy\in J$, so $1\in J$ and $J=R$. ∎
First isomorphism theorem For a ring homomorphism $\varphi:R\to S$: $\ker\varphi$ is an ideal and $R/\ker\varphi\cong\varphi(R)$. Evaluation maps $f\mapsto f(a)$ on $\mathbb{F}[x]$ are the main examples (Lecture 2).

§3 The ladder of domains

Field ⊂ ED ⊂ PID ⊂ UFD ⊂ ID
Question 7 Give an example of an ID that is not a UFD, a UFD that is not a PID, a PID that is not an ED.
$\mathbb{Z}[\sqrt{-5}]$: $6=2\cdot3=(1+\sqrt{-5})(1-\sqrt{-5})$, two different factorizations into irreducibles. $\mathbb{Z}[x]$ (or $\mathbb{F}[x,y]$): UFD, but $\langle 2,x\rangle$ is not principal. $\mathbb{Z}[\frac{1+\sqrt{-19}}2]$: a PID that is not Euclidean. Also: $\mathbb{Z}$ is a PID but $\mathbb{Z}[x]$ is not, whereas $\mathbb{F}[x]$ is a PID for a field $\mathbb{F}$.

§4 The polynomial ring $\mathbb{F}[x]$

Division algorithm For $f,g\in \mathbb{F}[x]$, $g\ne0$, there are unique $q,r$ with $f=qg+r$ and $r=0$ or $\deg r<\deg g$. So $\mathbb{F}[x]$ is a Euclidean domain with norm $\deg$. Units of $\mathbb{F}[x]$ are the non-zero constants; $\deg(fg)=\deg f+\deg g$.
Theorem 2 $\mathbb{F}[x]$ is a PID: every ideal is $\langle g\rangle$, where $g$ is a non-zero element of least degree in the ideal (unique up to a constant, so unique if taken monic). Consequently $\mathbb{F}[x]$ is a UFD and there is a gcd with Bezout: $\gcd(f,g)=uf+vg$.
Question 8 Prove Theorem 2.
Let $I\ne0$ be an ideal and $g\in I$ non-zero of least degree. For $f\in I$ write $f=qg+r$. Then $r=f-qg\in I$ with $\deg r<\deg g$, so $r=0$ and $f\in\langle g\rangle$. Thus $I=\langle g\rangle$. For Bezout, $\langle f,g\rangle=\langle d\rangle$; then $d\mid f,g$, $d=uf+vg$, and every common divisor divides $d$. ∎
Theorem 3 (key theorem) For non-zero $p\in \mathbb{F}[x]$: $p$ is irreducible $\iff$ $\langle p\rangle$ is a maximal ideal $\iff$ $\mathbb{F}[x]/\langle p\rangle$ is a field.
Question 9 Prove Theorem 3.
Use that every ideal containing $\langle p\rangle$ is $\langle g\rangle$ with $g\mid p$. The last equivalence is Theorem 1.
(⇒) Let $\langle p\rangle\subseteq I=\langle g\rangle$ (PID). Then $g\mid p$: $p=gq$. Irreducibility gives $g$ a unit ($I=\mathbb{F}[x]$) or $q$ a unit ($g$ associate to $p$, $I=\langle p\rangle$). So $\langle p\rangle$ is maximal.
(⇐) $\langle p\rangle$ maximal is proper, so $p$ is a non-unit, and $p\ne0$. If $p=ab$ then $\langle p\rangle\subseteq\langle a\rangle$: either $\langle a\rangle=\mathbb{F}[x]$ ($a$ a unit) or $\langle a\rangle=\langle p\rangle$, so $a=pu$ and $p=pub$, hence $ub=1$ and $b$ is a unit. So $p$ is irreducible. ∎
Theorem 4 (the correspondence) The map $f\mapsto\langle f\rangle$ is a bijection $$\{\text{monic irreducible polynomials in }\mathbb{F}[x]\}\ \longleftrightarrow\ \{\text{maximal ideals of }\mathbb{F}[x]\}.$$ Hence each maximal ideal is $\langle f\rangle$ for a unique monic irreducible $f$, and $\mathbb{F}[x]/\langle f\rangle$ is a field of degree $\deg f$ over $\mathbb{F}$.
Question 10 Prove Theorem 4.
Well defined: Theorem 3. Injective: $\langle f\rangle=\langle g\rangle$ means $f=ug$, $u\in \mathbb{F}^\times$; both monic forces $u=1$. Surjective: a maximal ideal $M=\langle h\rangle$ (PID). $h\ne0$ since $\langle0\rangle\subsetneq\langle x\rangle\subsetneq \mathbb{F}[x]$ is not maximal. By Theorem 3 $h$ is irreducible; dividing by its leading coefficient gives a monic generator, which is irreducible. ∎
Example: maximal ideals of $\mathbb{C}[x]$ are $\langle x-a\rangle$, $a\in\mathbb{C}$; of $\mathbb{R}[x]$: $\langle x-a\rangle$ and $\langle x^2+bx+c\rangle$ with $b^2<4c$.
Question 11 List all maximal ideals of $\mathbb{Z}_2[x]$ generated by polynomials of degree $\le2$.
Monic irreducibles over $\mathbb{Z}_2$ of degree 1: $x$, $x+1$. Degree 2: $x^2+x+1$ only ($x^2,x^2+1=(x+1)^2,x^2+x=x(x+1)$ are reducible). So the ideals are $\langle x\rangle,\langle x+1\rangle,\langle x^2+x+1\rangle$; the last gives a field with $2^2=4$ elements.
Root–factor theorem and degrees 2, 3 (1) $f(a)=0\iff(x-a)\mid f$ (divide: $f=(x-a)q+f(a)$). (2) A non-zero $f$ of degree $n$ has at most $n$ roots in a field. (3) For $\deg f\in\{2,3\}$: $f$ is irreducible over $\mathbb{F}$ $\iff$ $f$ has no root in $\mathbb{F}$. (For degree $\ge4$ a polynomial can be reducible with no roots, e.g. $(x^2+1)(x^2+2)$ over $\mathbb{R}$.)

Tools for irreducibility over $\mathbb{Q}$ Gauss lemma: a primitive $f\in\mathbb{Z}[x]$ is irreducible in $\mathbb{Z}[x]$ iff irreducible in $\mathbb{Q}[x]$; the product of primitive polynomials is primitive. Rational root test: a root $r/s$ (lowest terms) of $a_nx^n+\dots+a_0\in\mathbb{Z}[x]$ has $r\mid a_0$, $s\mid a_n$. Eisenstein: if for a prime $p$: $p\nmid a_n$, $p\mid a_0,\dots,a_{n-1}$, $p^2\nmid a_0$, then $f$ is irreducible over $\mathbb{Q}$. Reduction mod $p$: if $p\nmid a_n$ and $\bar f$ is irreducible over $\mathbb{Z}_p$, then $f$ is irreducible over $\mathbb{Q}$.
Question 12 Show $x^4+1$ is irreducible over $\mathbb{Q}$ (it has no rational root, and is reducible modulo every prime!).
Substitute $x\mapsto x+1$ and apply Eisenstein with $p=2$.
$(x+1)^4+1=x^4+4x^3+6x^2+4x+2$. Eisenstein with $p=2$: $2\mid4,6,4,2$ and $4\nmid2$. So it is irreducible, and so is $x^4+1$ (a factorization of $f(x)$ gives one of $f(x+1)$).

§5 Vector spaces and characteristic

Linear algebra over a field $\mathbb{F}$ A vector space $V$ over $\mathbb{F}$ has a basis (linearly independent spanning set); all bases have the same size $\dim_{\mathbb{F}}V$. If $\dim V=n$, any $n+1$ vectors are linearly dependent, any $n$ independent vectors form a basis, and a subspace $W$ has $\dim W\le\dim V$.
Fact used constantly later: if $\mathbb{K}\supseteq\mathbb{F}$ are fields then $\mathbb{K}$ is an $\mathbb{F}$-vector space.

$\mathbb{C}/\mathbb{R}$: $\{1,i\}$, dim 2. $\mathbb{Q}[x]/\langle x^2-2\rangle$: $\{1,\bar x\}$, dim 2. In general $\{1,\bar x,\dots,\bar x^{\,n-1}\}$, dim $n$: by division every coset has a unique representative of degree $
Characteristic The characteristic of a field $\mathbb{F}$ is the least $n\ge1$ with $n\cdot1=0$, or $0$ if none. It is either $0$ or a prime $p$. Then $\mathbb{F}$ contains a copy of $\mathbb{Q}$ (char 0) or $\mathbb{Z}_p$ (char $p$): the prime field. In particular a field of characteristic $p$ is never an extension of one of different characteristic.

§7 SAQ — Short Answer Questions

Answer on paper first, then reveal.

SAQ 1State: $I$ maximal in $R$ ⇔ ?
$R/I$ is a field.
SAQ 2Why is $\mathbb{F}[x]$ a PID?
It is Euclidean (division algorithm); an ideal is generated by an element of least degree.
SAQ 3State the bijection between maximal ideals and polynomials in $\mathbb{F}[x]$.
$f\mapsto\langle f\rangle$ from monic irreducible polynomials onto maximal ideals.
SAQ 4What are the units of $\mathbb{F}[x]$?
The non-zero constants.
SAQ 5When is a degree-3 polynomial irreducible over $\mathbb{F}$?
Exactly when it has no root in $\mathbb{F}$.
SAQ 6State Eisenstein's criterion.
If $p\nmid a_n$, $p\mid a_0,\dots,a_{n-1}$, $p^2\nmid a_0$, then $f\in\mathbb{Z}[x]$ is irreducible over $\mathbb{Q}$.
SAQ 7What are the possible characteristics of a field?
$0$ or a prime $p$.
SAQ 8Let $\mathbb{F}$ be a field and $f\in\mathbb{F}[x]$ of degree $n\ge 0$, $f\ne0$. Show $f$ has at most $n$ roots in $\mathbb{F}$. What happens if $\mathbb{F}$ is only an integral domain? A commutative ring?
Induct on $n$ using $f(a)=0\iff(x-a)\mid f$.
Proof. $n=0$: a non-zero constant has no root. If $f$ has no root we are done; else let $f(a)=0$, so $f=(x-a)q$ with $\deg q=n-1$. If $b\ne a$ is another root then $(b-a)q(b)=0$ and $b-a\ne0$, so $q(b)=0$ (this step needs: no zero divisors). By induction $q$ has at most $n-1$ roots, so $f$ has at most $n$. ∎
Integral domain: the statement still holds, by the same proof or by embedding the domain in its field of fractions. General commutative ring: false. In $\mathbb{Z}_8$, $x^2-1$ has four roots $1,3,5,7$; in $\mathbb{Z}_6$, $x^2-x$ has four roots $0,1,3,4$. Zero divisors break the cancellation step.
SAQ 9Let $f\in\mathbb{F}[x]$ have degree $2$ or $3$. Show: $f$ is reducible over $\mathbb{F}$ if and only if $f$ has a root in $\mathbb{F}$. What about degree $4$? (Consider $(x^2+1)(x^2+2)$.)
(⇒) If $f=gh$ with both non-constant, then $\deg g+\deg h\in\{2,3\}$ forces a factor of degree $1$, say $ax+b$ ($a\ne0$), whose root $-b/a$ is a root of $f$. (⇐) If $f(a)=0$ then $f=(x-a)q$ with $\deg q=\deg f-1\ge1$, so $q$ and $x-a$ are non-units: $f$ is reducible. ∎
Degree 4 fails: $f=(x^2+1)(x^2+2)$ is reducible over $\mathbb{Q}$ (and over $\mathbb{R}$), but $x^2=-1$ and $x^2=-2$ have no solutions in $\mathbb{R}$, so $f$ has no root in $\mathbb{Q}$ or $\mathbb{R}$. Only "has a root ⇒ reducible" survives (for $\deg\ge2$); the converse needs degree $\le3$. Another example: $x^4+4=(x^2+2x+2)(x^2-2x+2)$ over $\mathbb{Q}$.
SAQ 10Every linear polynomial in $\mathbb{F}[x]$ has a root in $\mathbb{F}$, yet it is irreducible. Does this contradict SAQ 9?
$ax+b$ with $a\ne0$ has the root $-b/a\in\mathbb{F}$. It is irreducible: if $ax+b=gh$ then $\deg g+\deg h=1$, so one factor has degree $0$, i.e. is a non-zero constant, a unit. No contradiction: "has a root ⇒ reducible" needs $\deg f\ge2$ (then $f=(x-a)q$ with $q$ non-constant). For $\deg f=1$, $q$ is a constant, a unit.
SAQ 11If $\alpha$ is a root of $f(x)\in\mathbb{F}[x]$, show $\alpha$ is a root of $\lambda f$ for every $\lambda\in\mathbb{F}$. Why does this let us work with monic polynomials?
$(\lambda f)(\alpha)=\lambda f(\alpha)=\lambda\cdot0=0$. (For $\lambda=0$ this is the zero polynomial, which every element kills; for $\lambda\ne0$, $f$ and $\lambda f$ have exactly the same roots.) Taking $\lambda=a_n^{-1}$ makes $f$ monic without changing roots, so questions about roots and minimal polynomials may be asked for monic polynomials.
SAQ 12When are two polynomials $f,g\in\mathbb{F}[x]$ associates? How many monic associates does a non-zero polynomial have?
$f,g$ are associates iff $f=\lambda g$ for some $\lambda\in\mathbb{F}^\times$ (the units of $\mathbb{F}[x]$ are the non-zero constants). Equivalently $f\mid g$ and $g\mid f$, or $\langle f\rangle=\langle g\rangle$. They then have the same degree and the same roots. Each non-zero $f$ has exactly one monic associate ($a_n^{-1}f$). Example: $x^2+1$ and $3x^2+3$ are associates in $\mathbb{Q}[x]$; $x^2+1$ and $x^2+2$ are not.
