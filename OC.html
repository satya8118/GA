Order Classes of Groups

A complete characterization of groups classified by the orders of their elements — from the trivial group to constructions for every $k \in \mathbb{N}$.

Section 1

The Equivalence Relation

Let $G$ be a group. For $a, b \in G$, define $a \sim b$ if and only if $o(a) = o(b)$, where $o(x)$ denotes the order of $x$.

Proof that $\sim$ is an equivalence relation

Reflexive: For every $a \in G$, $o(a) = o(a)$, so $a \sim a$.

Symmetric: If $a \sim b$, then $o(a) = o(b)$, hence $o(b) = o(a)$, so $b \sim a$.

Transitive: If $a \sim b$ and $b \sim c$, then $o(a) = o(b) = o(c)$, so $a \sim c$.

Therefore $\sim$ is an equivalence relation on $G$. Its equivalence classes are the order classes of $G$.

The Identity Always Forms Its Own Class

The order of the identity is $o(e) = 1$. If $o(g) = 1$ for some $g \in G$, then $g^1 = e$ implies $g = e$. Therefore:

$$\{e\} = \{g \in G : o(g) = 1\}$$

The singleton $\{e\}$ is always one order class. This means every group has at least one order class, and if a group has exactly $k$ order classes, one of them is always $\{e\}$ with the remaining $k-1$ classes consisting of non-identity elements.

Section 2

Groups with Exactly One Order Class

Theorem

A group $G$ has exactly one order class if and only if $G = \{e\}$ (the trivial group).

Proof

Since $\{e\}$ is always a distinct order class, having exactly one class forces $G = \{e\}$. Conversely, the trivial group clearly has one order class.

Section 3

Groups with Exactly Two Order Classes

One class is $\{e\}$ (order 1). All non-identity elements must share a single order $d$.

Key observation

If $d$ is finite and composite, say $d = mn$ with $1 < m < d$, then for any $g$ with $o(g) = d$, the element $g^m$ has order $n \neq 1, d$ — a contradiction. Hence $d$ is either prime or infinite.

Theorem (Characterization)

$G$ has exactly two order classes if and only if one of the following holds:

Type A: Torsion-Free

Every non-identity element has infinite order. Equivalently, $G$ is a torsion-free group.

Infinite Examples: $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$, any free group, any torsion-free abelian group.

Type B: Exponent $p$

Every non-identity element has order $p$ for a fixed prime $p$. Equivalently, $G$ is a group of exponent $p$.

Finite Cyclic $\mathbb{Z}/p\mathbb{Z}$   Finite Non-abelian Heisenberg group mod $p$ (for odd $p$)

Why exponent 2 forces abelian

If every element has order dividing 2, then $(ab)^2 = e$ for all $a, b$, so $abab = e$, giving $aba = b^{-1} = b$. Hence $ab = ba$.

Therefore, the only groups of exponent 2 are the elementary abelian 2-groups $(\mathbb{Z}/2\mathbb{Z})^n$.

Non-abelian groups of exponent $p$ (odd $p$)

For odd primes $p$, non-abelian groups of exponent $p$ exist. The smallest example is the Heisenberg group over $\mathbb{Z}/p\mathbb{Z}$:

$$H_p = \left\{ \begin{pmatrix} 1 & a & c \\ 0 & 1 & b \\ 0 & 0 & 1 \end{pmatrix} : a, b, c \in \mathbb{Z}/p\mathbb{Z} \right\}$$

This group has order $p^3$, is non-abelian, and every non-identity element satisfies $X^p = I$, so all have order $p$. It provides a non-abelian, non-cyclic example for $k = 2$.

Section 4

Groups with Exactly Three Order Classes

The order set must be $\{1, d_1, d_2\}$ where $d_1 < d_2$. By the same divisor-closed argument, $d_1$ must be prime. Three distinct types arise:

Type I: $\{1,\; p,\; p^2\}$ — Prime Power Chain

Groups of exponent $p^2$ that are not of exponent $p$ (i.e., some element has order $p^2$).

Finite Cyclic $\mathbb{Z}/p^2\mathbb{Z}$

Finite Non-cyclic: $(\mathbb{Z}/p\mathbb{Z})^n \times \mathbb{Z}/p^2\mathbb{Z}$ for any $n \geq 1$

Finite Non-abelian For $p = 2$: $D_4$, $Q_8$. For odd $p$: the non-abelian group of order $p^3$ with exponent $p^2$, presented as $\langle x, y \mid x^{p^2} = e,\; y^p = e,\; yxy^{-1} = x^{1+p} \rangle$.

Infinite $\mathbb{Z} \times \mathbb{Z}/p^2\mathbb{Z}$ — orders $\{1, p, p^2, \infty\}$... wait, that's four classes.

Type II: $\{1,\; p,\; q\}$ — Mixed Primes ($p \neq q$)
Crucial fact

No cyclic group realizes this order set. Since $d(pq) = 4$, every $\mathbb{Z}/n\mathbb{Z}$ with these orders would also contain elements of order $pq$. This set is exclusively non-cyclic.

Finite Non-abelian The symmetric group $S_3$ (orders $\{1, 2, 3\}$) — the smallest example.

Finite Non-abelian More generally, the non-abelian group of order $pq$ (where $q \mid p - 1$), realized as a semidirect product $\mathbb{Z}/q\mathbb{Z} \rtimes \mathbb{Z}/p\mathbb{Z}$.

Type III: $\{1,\; p,\; \infty\}$ — Finite + Infinite

Infinite $\mathbb{Z} \times \mathbb{Z}/p\mathbb{Z}$: elements with non-zero first component have infinite order; $(0, m)$ for $m \neq 0$ have order $p$.

Infinite Non-abelian The infinite dihedral group $D_\infty = \langle r, s \mid s^2 = e,\; srs = r^{-1} \rangle$: rotations $r^n$ ($n \neq 0$) have infinite order, all reflections have order 2.

More generally: any torsion-free group $T \times \mathbb{Z}/p\mathbb{Z}$.

Verification: $D_4$ has orders $\{1, 2, 4\}$

$D_4 = \langle r, s \mid r^4 = s^2 = e,\; srs = r^{-1} \rangle$ has 8 elements: $\{e, r, r^2, r^3, s, sr, sr^2, sr^3\}$.

Orders: $o(e) = 1$, $o(r) = o(r^3) = 4$, $o(r^2) = 2$, and all four reflections have order 2. So the order classes are $\{e\}$, $\{r^2, s, sr, sr^2, sr^3\}$ (order 2), and $\{r, r^3\}$ (order 4). Three classes. $\square$

Verification: $Q_8$ has orders $\{1, 2, 4\}$

$Q_8 = \{\pm 1, \pm i, \pm j, \pm k\}$ with $i^2 = j^2 = k^2 = -1$, $ij = k$, $jk = i$, $ki = j$.

Orders: $o(1) = 1$, $o(-1) = 2$, and $o(\pm i) = o(\pm j) = o(\pm k) = 4$. Three order classes. $\square$

Section 5

The Downward-Closed Structure of Order Sets

Theorem (Divisor-Closed Property)

Let $\Omega(G) = \{o(g) : g \in G\}$ be the set of element orders of $G$. Then $\Omega(G)$ is downward closed under divisibility: if $d \in \Omega(G)$ and $m \mid d$ with $m \geq 1$, then $m \in \Omega(G)$.

Proof

If $d \in \Omega(G)$, there exists $g \in G$ with $o(g) = d$. For any divisor $m \mid d$, write $d = mk$. Then $o(g^k) = d / \gcd(d, k) = d/k = m$ (since $k \mid d$). Hence $m \in \Omega(G)$.

This means the order set $\Omega(G)$ is completely determined by its maximal elements under divisibility. If the maximal orders are $m_1, \ldots, m_r$, then:

$$\Omega(G) = \{d \geq 1 : d \mid m_i \text{ for some } i\} \;\cup\; \{\infty\} \text{ if applicable}$$
Consequence

Not every downward-closed set arises from a cyclic group. The set $\{1, 2, 3\}$ is downward-closed, but $\{d : d \mid n\} = \{1, 2, 3, 6\} \neq \{1, 2, 3\}$ for any $n$. Yet $S_3$ realizes $\{1, 2, 3\}$. Non-cyclic groups unlock order sets that cyclic groups cannot reach.

What this means for counting

If $G$ has exactly $k$ order classes, then $\Omega(G)$ is a downward-closed set of size $k$ containing 1. For cyclic groups $\mathbb{Z}/n\mathbb{Z}$, this set is exactly $\{d : d \mid n\}$, so the number of order classes equals $d(n)$, the divisor function.

Section 6

For Every $k \in \mathbb{N}$

Theorem (Existence)

For every positive integer $k$, there exists a group with exactly $k$ order classes.

Proof via the divisor function

We show that for every $k \geq 1$, there exists $n \in \mathbb{N}$ with $d(n) = k$. Then $\mathbb{Z}/n\mathbb{Z}$ has exactly $k$ order classes.

$k = 1$: $n = 1$, $d(1) = 1$.

$k$ prime: Take $n = p^{k-1}$ for any prime $p$. Then $d(n) = (k-1) + 1 = k$.

$k$ composite: Write $k = ab$ with $a, b \geq 2$. Take distinct primes $p_1, p_2$ and set $n = p_1^{a-1} \cdot p_2^{b-1}$. Then $d(n) = a \cdot b = k$.

For general composite $k$, factor $k = \prod_{i=1}^{r} a_i$ (with each $a_i \geq 2$) and take $n = \prod_{i=1}^{r} p_i^{a_i - 1}$ for distinct primes $p_i$. $\square$

The Obvious Answer: Cyclic $p$-Power Groups

The user correctly identifies $\mathbb{Z}/p^{k-1}\mathbb{Z}$ as one construction. Its order classes are:

$$\{1\},\quad \{g : o(g) = p\},\quad \{g : o(g) = p^2\},\quad \ldots,\quad \{g : o(g) = p^{k-1}\}$$

These are the "linear chain" order sets. But there are many other groups — and even other cyclic groups — with exactly $k$ order classes.

General Constructions Beyond Cyclic $p$-Powers

Construction 1: Non-prime-power cyclic groups

If $n$ has exactly $k$ divisors, then $\mathbb{Z}/n\mathbb{Z}$ has exactly $k$ order classes. For composite $k$, such $n$ need not be a prime power.

Examples: $k = 4$: $n = 6 = 2 \cdot 3$ (not a prime power). $k = 6$: $n = 12 = 2^2 \cdot 3$ or $n = 45 = 3^2 \cdot 5$. $k = 8$: $n = 24$, $n = 30$, $n = 54$, etc.

Construction 2: Direct products with elementary abelian factors

If $G$ has order classes $\{1, p, p^2, \ldots, p^m\}$, then for any $n \geq 1$, the group $(\mathbb{Z}/p\mathbb{Z})^n \times G$ has the same order classes. This is because $\operatorname{lcm}(p, p^j) = p^j$ for all $j$.

This produces infinitely many non-isomorphic groups with the same $k$ order classes.

Construction 3: Torsion-free extension

If $G$ is a non-trivial group with exactly $k$ order classes, then $\mathbb{Z} \times G$ has exactly $k + 1$ order classes (adding $\infty$). More generally, any torsion-free group $T \times G$ gives $k + 1$ classes.

Construction 4: Non-abelian groups

Non-abelian groups can realize order sets that no cyclic group can. The prototypical example: $S_3$ realizes $\{1, 2, 3\}$, which is not the divisor set of any integer.

More generally, semidirect products $\mathbb{Z}/q\mathbb{Z} \rtimes \mathbb{Z}/p\mathbb{Z}$ (when $q \mid p - 1$) realize $\{1, p, q\}$, and non-abelian $p$-groups of order $p^3$ with exponent $p^2$ realize $\{1, p, p^2\}$.

Open-ended question

Given a downward-closed set $S \subset \mathbb{N}$ with $1 \in S$ and $|S| = k$, when does there exist a group $G$ with $\Omega(G) = S$? The answer is known to be "yes" for many sets, but a complete characterization remains an interesting open problem. The obstruction is that in direct products, lcm can introduce unwanted orders — non-abelian structures can sometimes avoid this.
